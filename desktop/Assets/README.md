# Song Study icon

`SongStudy.png` is the original generated artwork with transparency. `build_app.py` creates the standard 16–1024 pixel macOS representations and bundles `SongStudy.icns`. The app's `CFBundleIconFile` points to that resource, and the launch delegate explicitly sets `NSApp.applicationIconImage` from it so the running Dock icon uses the same artwork. Keep this source artwork in the repository so rebuilds retain the icon.

## Generation prompt

Create the final production macOS app icon for Song Study, a thoughtfully designed music arrangement listening app centered on sections, energy and isolated instrument parts. One single icon, square 1024 by 1024 canvas. Transparent outside a large inset macOS continuous rounded square dark charcoal tile. Tile occupies about 82% of canvas width, centered, corners generously rounded. Within the tile design a bold minimal abstract musical arrangement emblem: three thick horizontally arranged phrase ribbons or blocks, staggered in time and separated by generous negative space, with gently shaped heights suggesting musical energy. Restrained lavender and warm ivory accents, optionally a muted blue lavender third phrase. One thin but clearly visible ivory vertical playhead unifies the phrase rows near the center, with a tiny downward triangular cap. The emblem should be an original coherent recognizable geometric logo rather than a literal screenshot or busy equalizer. Calm high-end music software visual identity. Excellent silhouette at 32px, enough weight and contrast at 16px. Flat precision geometry, modest depth of tile only, no chrome shine, no glow, no neon, no gradients on the emblem, no letters, no text, no musical note clipart, no headphones, no extra objects. Straight-on app icon artwork alone, not a mockup, not a contact sheet. Carefully balanced optical proportions, substantial inner margin. Genuine transparent alpha background around the tile.
